# Day 1: Getting Started

Day 1 introduces the RoboLink robot project and the basic electronics ideas students need before programming the Arduino. Students review voltage, current, resistance, LEDs, switches, power, ground, and safe circuit-building habits.

## Learning Goals

By the end of Day 1, students should be able to:

- Describe the goal of the RoboLink robot project.
- Identify common electronics parts used in the course.
- Explain the difference between power, ground, input, and output.
- Recognize the Arduino Nano and the main pins used in later labs.
- Follow basic circuit safety rules before connecting power.
- Prepare for Day 2, where students start using the Arduino IDE.

## Safety Reminders

- Ask your instructor to check wiring before connecting power.
- Do not connect 5V directly to GND.
- Use resistors with LEDs.
- Disconnect power before changing a circuit.
