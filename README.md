# Mini Course Program 2026 - RoboLink

Course: RoboLink: Build and Drive Your Smartphone-Controlled Robot

Instructors:
- Dr. Mahmoud Sayed
- Mahmoud Yassin

This repository contains the student materials for the RoboLink mini course. Each folder is organized by course day.

## Repository Structure

- `Day1_Getting_Started/` - Course introduction and setup
- `Day2_Arduino_Basics/` - Arduino programming basics
- `Day3_Sensors/` - Sensor concepts and activities
- `Day4_Serial_Monitor_Robot/` - Serial monitor robot control
- `Day5_RoboLink_Smartphone_Control/` - Bluetooth smartphone robot control

## Included Files

Day 4 includes:
- `Lab4_Serial_Monitor_Robot.pdf`

Day 5 includes:

- `Lab5_Part2_RoboLink.pdf`

## Software

- Arduino IDE
- Arduino-compatible board support package

## Hardware

- Arduino-compatible microcontroller
- L9110 motor driver
- DC motors and robot chassis
- HC-05 Bluetooth module
- Smartphone with Bluetooth control app
