# Mini Course Program 2026 - RoboLink

Course: RoboLink: Build and Drive Your Smartphone-Controlled Robot

Instructors:
- Dr. Mahmoud Sayed
- Mahmoud Yassin

This repository contains the daily materials, code, handouts, and assets for the RoboLink mini course.

## Repository Structure

- `Day1_Getting_Started/` - Course introduction and setup material
- `Day2_Arduino_Basics/` - Arduino and PlatformIO basics
- `Day3_Robot_Chassis_and_Motors/` - Robot chassis, motor driver, and wiring
- `Day4_Serial_Monitor_Robot/` - Serial monitor controlled robot
- `Day5_RoboLink_Smartphone_Control/` - Bluetooth smartphone controlled robot

## Software

- Visual Studio Code
- PlatformIO
- Arduino framework

## Hardware

- Arduino-compatible microcontroller
- L9110 motor driver
- DC motors and robot chassis
- HC-05 Bluetooth module
- Smartphone with Bluetooth control app
