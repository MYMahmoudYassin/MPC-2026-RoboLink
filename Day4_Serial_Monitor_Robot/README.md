# Day 4 - Serial Monitor Robot

This folder contains the Day 4 handout and Arduino sketch for controlling the robot from the serial monitor.

Topics:
- Serial commands
- Robot movement from the computer
- L9110 motor driver control
- Forward, backward, left, right, and stop commands

Included files:
- `Lab4_Serial_Monitor_Robot.pdf`
- `Lab4_Serial_Monitor_Robot/Lab4_Serial_Monitor_Robot.ino`

To use the code, open `Lab4_Serial_Monitor_Robot/Lab4_Serial_Monitor_Robot.ino` in the Arduino IDE.
