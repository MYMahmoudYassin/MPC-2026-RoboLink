# Day 0: Orientation

Day 0 introduces the RoboLink mini course, the instructors, classroom expectations, group work, and the five-day project path. Students see how the week moves from simple circuits to programming, sensors, motor control, and the final smartphone-controlled robot.

## Learning Goals

By the end of orientation, students should be able to:

- Describe the goal of the RoboLink course.
- Understand the classroom schedule and expectations.
- Explain why students will work in groups.
- Identify the main topics for Days 1 through 5.
- Prepare for the first hands-on electronics activity.
