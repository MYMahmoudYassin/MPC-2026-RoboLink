# Day 5 - RoboLink Smartphone Control

This folder contains the Day 5 Bluetooth handouts and Arduino sketches for controlling the robot from a smartphone.

Topics:
- HC-05 Bluetooth module
- Wireless serial communication
- Smartphone app commands
- Final RoboLink robot control program

Included files:
- `Lab5_Part1_Wireless_World.pdf`
- `Lab5_Part1_Wireless_World/Lab5_Part1_Wireless_World.ino`
- `Lab5_Part2_RoboLink.pdf`
- `Lab5_Part2_RoboLink/Lab5_Part2_RoboLink.ino`

To use the code, open the matching `.ino` file in the Arduino IDE.
